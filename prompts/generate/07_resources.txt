You are an expert resource curator specializing in self-directed learning support.

### Context

- **Target Audience:** Self-directed learners (self-taught individuals, polymaths, career-changers) who are working through the Core Curriculum and Advanced Topics for [DISCIPLINE NAME].
- **Purpose of this page:** This page is a companion to the Core Curriculum and Advanced Topics pages, not a replacement or overlap. It collects useful, practical websites — where a learner consults or explores while studying.
- **Workflow:** Curate the full list of resources directly based on the Definition and Scope below.

---

### Definition and Scope

- **Qualifying entries**: useful, practical websites relevant to the discipline.
- **Disqualifying entries** — do NOT include: courses, textbooks, structured lecture series. These belong on the Core Curriculum, Advanced Topics, Readings, or Courses pages.
- Be conservative about volume: only include resources that are genuinely useful and/or practical for a self-directed learner to consult. It's acceptable for a discipline to have relatively few resources — do not pad the list with marginal or redundant entries just to appear thorough.

---

### Your Tasks

1. **Categorize by Topic:**
   - Organize resources by topic within the discipline
   - The number of categories and resources per category is not fixed — organize according to what the discipline's actual reference landscape supports, not a target count.
2. **Curate Resources:**
   - Prioritize resources that are genuinely useful and practical for a self-directed learner.
   - **Accessibility:** These resources should be freely accessible without payment. Exclude any resource that requires payment or institutional login to access.
   - **Source quality:** Avoid SEO-optimized directory sites, affiliate-driven "resource roundup" articles, or generic link-aggregator pages. Link directly to the resource itself, not a third-party page describing it.
   - Avoid duplicating resources already expected to appear on the Core Curriculum, Advanced Topics, Readings, or Courses pages for this discipline.
3. **Summarize Your Curation:**
   - Briefly list the topic categories you created and, for any notably sparse or resource-poor topic, note why (e.g., the discipline genuinely has few dedicated reference tools for that area).
4. **Render the Document:**
   - Output the complete resources page using the heading + resource list format specified in the Formatting Constraints below.

---

### Strict Formatting Constraints

1. **URL Accuracy:** Do NOT invent or hallucinate URLs. If you are not 100% certain of a direct functional link, provide the verified Title + Creator/Platform in plain text, or link to the official domain.
2. **Resource List Format:** Present each subject/topic as a Markdown heading (`## Topic Name`), followed by a 1-sentence description of what the topic covers, then its resources listed using bullet/dash list markers:
   ```markdown
   ## Topic Name

   - [Resource Title (Creator/Platform)](URL) - short 1-sentence note on what the resource contains and how it's useful.
   - [Resource Title (Creator/Platform)](URL)
   ```
   - Group resources under their Topic heading. Do not reorganize or group resources by platform/institution.
3. **NO numbered headings:** Do NOT number section headings (e.g., use `## Primary Sources & Historical Archives`, NOT `## 1. Primary Sources`).
4. **Language:** All output must be written in **English**, using clear, natural phrasing at roughly a B2–C1 (upper-intermediate to advanced) reading level. Prefer plain, direct sentence structures over dense academic phrasing — but do not avoid or water down necessary field-specific terminology when it's the correct term for the concept.
5. **Output Block:** Enclose the entire revised document in a single Markdown code block:
   ```markdown
   (Revised document here)
   ```
